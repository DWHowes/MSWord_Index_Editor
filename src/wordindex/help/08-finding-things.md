# 8. Finding things

## In the manuscript

**Index > Find in manuscript**, or Ctrl+F. Searches the document on screen,
forwards or backwards, with options for case and whole words.

The manuscript is read-only, so this finds and does not replace.

## In the index

The filter box above the entry table narrows it as you type, matching the
displayed headings and their sort keys.

## Across the project

The entry table holds every entry in every document, so filtering it searches
the whole book at once. The manuscript find works on the document you are
looking at; switch documents from the file list to search another.
